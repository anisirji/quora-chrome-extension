# Quora Growth Bot (Chrome extension)

Extracts Quora questions, drafts AI answers and posts replies, for social media growth marketing.

## Files

- `manifest.json`: the extension (Manifest V3)
- `content.js`: reads questions on Quora pages
- `background.js`: the background worker
- `popup.html` / `popup.js`: the toolbar popup
- `options.html` / `options.js`: settings

The newest unfinished changes are on the `latest-local-work` branch.

## Try it

1. Open `chrome://extensions` and turn on Developer mode.
2. Click **Load unpacked** and pick this folder.
3. Open the extension's options to add your settings.
